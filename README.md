### Step 1: Download SR Legacy

USDA SR Legacy has around 7,800 whole foods with complete amino acid profiles. The compressed file is small (~8 MB).

1. Go to the [USDA FoodData Central Downloads page](https://fdc.nal.usda.gov/download-datasets.html).
2. Download the ZIP file titled **"SR Legacy (October 2019)"** (CSV format).
3. Unzip the folder. You only need three files from that folder:
* `food.csv`
* `nutrient.csv`
* `food_nutrient.csv`


4. Place them in the same directory as your Python script.
